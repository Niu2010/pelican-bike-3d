# 🐦 鹈鹕骑车抓鱼 · Pelican Coast Ride

戴头盔墨镜、脖子系红围巾的鹈鹕，在海岸公路上骑车抓鱼。纯 Three.js 实时 3D，所有模型、纹理、音效、音乐都由代码程序化生成，无任何外部素材。

**在线游玩：https://niu2010.github.io/pelican-bike-3d/**

## 操作
| 按键 | 作用 |
|---|---|
| W / S | 加速 / 减速 |
| A / D | 变道抓鱼 |
| 空格 | 跳跃（接跃出海面的飞鱼） |
| T | 展翅抬前轮 |
| C / 1–5 | 切换镜头 |
| H | 成就面板 |
| M | 静音 |
| 点击画面 | 按车铃 |

手机上会出现触屏按钮。7 秒不操作，鹈鹕会自动驾驶去追鱼。

## 特性
- **布料物理围巾**：Verlet 质点 + 距离/剪切/抗弯约束，受相对风速、阵风和身体碰撞影响
- **昼夜循环**：黄昏 → 入夜 → 星空月夜，带闪烁星空、流星、月亮、路灯光斑、车灯、灯塔光束
- **海面**：5 层 Gerstner 波浪着色器（菲涅尔反射、日/月高光、浪尖泡沫），沙滩斜坡上的岸边碎浪与水花
- **玩法**：路面鱼骑过去低头叼起，飞鱼需要跳起来接；金鱼 5 分；连击倍率
- **14 个成就**（本地保存）
- **5 种镜头**：追尾、侧面、正面特写、电影运镜（自动切换 5 个机位）、鹈鹕第一人称视角
- **WebAudio 实时合成**：鼓、贝斯、和弦、琶音，节奏跟随踏频；风声、海浪、抓鱼/跳跃/成就音效
- **自适应画质**：按实测帧率在 省电 / 中 / 高 / 极致 之间自动切换（像素比、阴影、泛光）
